¿Qué es HTML5?

HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web. No es un lenguaje de programación; es un lenguaje de estructura y contenido. HTML5 es la quinta y actual versión, lanzada oficialmente en 2014 por el W3C.

Cada página que visitas en internet está construida sobre HTML. El navegador lee el código HTML y lo convierte en la página visual que ves en pantalla. HTML trabaja en equipo con CSS (estilos) y JavaScript (interactividad).

Dato clave: HTML5 añadió nuevas etiquetas semánticas (<header>, <article>, <section>), soporte nativo para audio y video, APIs de geolocalización, canvas 2D/3D y almacenamiento local, eliminando la necesidad de plugins como Flash.
  • 1
    HTML da la estructuraDefine qué es cada elemento: un párrafo, un título, una imagen, un botón.
  • 2
    CSS da el estiloControla colores, tipografías, tamaños y posicionamiento visual.
  • 3
    JavaScript da la lógicaAgrega interactividad, animaciones dinámicas y comunicación con servidores.

Estructura base de un documento HTML5

Todo documento HTML5 parte de una estructura mínima estándar. Esta plantilla es la base de cualquier página web y debe incluirse siempre completa.

index.html
<!-- Declaración del tipo de documento -->
<!DOCTYPE html>

<!-- Elemento raíz, define el idioma -->
<html lang="es">

  <!-- Cabecera: metadatos invisibles -->
  <head>
    <meta charset="UTF-8"/>
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0"/>
    <title>Título de mi página</title>
    <link rel="stylesheet" href="styles.css"/>
  </head>

  <!-- Cuerpo: todo el contenido visible -->
  <body>
    <h1>¡Hola, Mundo!</h1>
    <p>Mi primera página web.</p>
    <script src="app.js"></script>
  </body>

</html>
EtiquetaFunción
<!DOCTYPE html>Declara que el documento es HTML5. Va siempre en la primera línea.
<html lang="es">Elemento raíz. lang indica el idioma para accesibilidad y SEO.
<head>Contiene metadatos: título, charset, links a CSS, scripts.
<meta charset="UTF-8">Define la codificación de caracteres. UTF-8 soporta tildes y ñ.
<meta name="viewport">Hace la página responsiva en dispositivos móviles.
<title>Título que aparece en la pestaña del navegador.
<body>Contiene todo el contenido visible de la página.

Vínculos e imágenes

Los hipervínculos (<a>) son el corazón de la web: conectan páginas entre sí. Las imágenes (<img>) son elementos de reemplazo que cargan recursos externos.

enlaces.html
<!-- Enlace externo -->
<a href="https://www.google.com"
   target="_blank"
   rel="noopener noreferrer">
  Ir a Google
</a>

<!-- Enlace interno (misma web) -->
<a href="contacto.html">Contacto</a>

<!-- Enlace a sección (ancla) -->
<a href="#seccion2">Ir a Sección 2</a>
<section id="seccion2">...</section>

<!-- Enlace mailto y tel -->
<a href="mailto:correo@ejemplo.com">Enviar correo</a>
<a href="tel:+529611234567">Llamar</a>

<!-- Imágenes -->
<img src="foto.jpg"
     alt="Descripción de la imagen"
     width="400"
     height="300"
     loading="lazy"/>

<!-- Imagen responsive con picture -->
<picture>
  <source media="(max-width:600px)"
          srcset="pequeña.jpg"/>
  <img src="grande.jpg" alt="Responsive"/>
</picture>
Importante: El atributo alt en las imágenes es obligatorio por accesibilidad. Si la imagen no carga, el navegador mostrará el texto alt. Los lectores de pantalla lo usan para describir la imagen a personas con discapacidad visual.

Tablas

Las tablas sirven para presentar datos en formato de filas y columnas. No deben usarse para diseñar layouts; para eso existe CSS Grid y Flexbox.

tabla.html
<table>
  <!-- Encabezado de tabla -->
  <thead>
    <tr>  <!-- table row: fila -->
      <th>Lenguaje</th>  <!-- table header -->
      <th>Año</th>
      <th>Uso</th>
    </tr>
  </thead>

  <!-- Cuerpo de tabla -->
  <tbody>
    <tr>
      <td>HTML</td>  <!-- table data -->
      <td>1991</td>
      <td>Estructura web</td>
    </tr>
    <tr>
      <td colspan="2">CSS + JS</td>  <!-- fusiona 2 cols -->
      <td>Estilo e interacción</td>
    </tr>
  </tbody>

  <!-- Pie de tabla -->
  <tfoot>
    <tr>
      <td colspan="3">Fuente: W3C</td>
    </tr>
  </tfoot>
</table>

Formularios HTML5

Los formularios permiten al usuario enviar datos. HTML5 añadió muchos tipos de entrada nuevos que mejoran la experiencia y validan datos automáticamente.

formulario.html
<form action="/enviar" method="POST">

  <!-- Texto simple -->
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre"
         name="nombre" required
         placeholder="Tu nombre"/>

  <!-- Tipos HTML5 nuevos -->
  <input type="email"    placeholder="correo@mail.com"/>
  <input type="tel"      placeholder="961 123 4567"/>
  <input type="number"   min="0" max="100"/>
  <input type="date"/>
  <input type="color"/>
  <input type="range"    min="0" max="10"/>
  <input type="file"     accept=".pdf,.jpg"/>
  <input type="search"   placeholder="Buscar..."/>
  <input type="url"/>
  <input type="password"/>
  <input type="checkbox"/> Acepto términos
  <input type="radio" name="opcion"/> Opción A
  <input type="radio" name="opcion"/> Opción B

  <!-- Área de texto -->
  <textarea rows="4" cols="40"></textarea>

  <!-- Selector desplegable -->
  <select name="pais">
    <option value="mx">México</option>
    <option value="es">España</option>
  </select>

  <!-- Botones -->
  <button type="submit">Enviar</button>
  <button type="reset">Limpiar</button>

</form>

Etiquetas semánticas de HTML5

Las etiquetas semánticas son la gran innovación de HTML5. A diferencia de usar <div> para todo, estas etiquetas describen el significado del contenido, lo que mejora la accesibilidad, el SEO y la mantenibilidad del código.

semantica.html
<body>

  <!-- Cabecera de la página o sección -->
  <header>
    <nav>  <!-- Navegación principal -->
      <a href="/">Inicio</a>
    </nav>
  </header>

  <!-- Contenido principal (solo uno por página) -->
  <main>

    <!-- Sección temática con título -->
    <section>
      <h2>Noticias</h2>

      <!-- Contenido independiente y reutilizable -->
      <article>
        <h3>Título noticia</h3>
        <p>Contenido del artículo...</p>
        <footer>  <!-- footer del article -->
          <time datetime="2025-03-15">15 marzo 2025</time>
        </footer>
      </article>
    </section>

    <!-- Contenido relacionado / lateral -->
    <aside>
      <p>Publicidad o contenido relacionado</p>
    </aside>

    <!-- Grupo de contenidos con leyenda -->
    <figure>
      <img src="grafico.png" alt="Gráfico"/>
      <figcaption>Fig. 1: Crecimiento web</figcaption>
    </figure>

    <!-- Detalles colapsables (accordion nativo) -->
    <details>
      <summary>¿Qué es HTML5?</summary>
      <p>Es la quinta versión del lenguaje HTML.</p>
    </details>

    <!-- Barra de progreso nativa -->
    <progress value="70" max="100">70%</progress>

    <!-- Marcador de resultado -->
    <meter min="0" max="10" value="7">7/10</meter>

  </main>

  <!-- Pie de página global -->
  <footer>
    <p>© 2025 Mi sitio web</p>
    <address>Tuxtla, Chiapas, México</address>
  </footer>

</body>
EtiquetaUso semántico
<header> HTML5Encabezado de página o sección. Puede contener logo, nav, título.
<nav> HTML5Bloque de navegación principal o secundaria.
<main> HTML5Contenido principal único de la página. Solo uno por documento.
<section> HTML5Sección temática del documento. Debe tener un título h2-h6.
<article> HTML5Contenido autónomo reutilizable: post, noticia, tarjeta.
<aside> HTML5Contenido secundario o relacionado: barra lateral, publicidad.
<footer> HTML5Pie de página o sección. Créditos, links, copyright.
<figure> HTML5Contenido ilustrativo: imagen, video, diagrama.
<figcaption> HTML5Leyenda o descripción del figure.
<time> HTML5Fecha u hora con atributo datetime legible por máquinas.
<details> HTML5Acordeón nativo: muestra u oculta contenido al hacer clic.
<summary> HTML5Título visible del <details>.
<mark> HTML5Texto resaltado por relevancia en el contexto.
<progress> HTML5Barra de progreso nativa del navegador.
<meter> HTML5Medida escalar en un rango conocido (batería, valoración).

Multimedia: Audio, Video y Canvas

HTML5 eliminó la necesidad de Flash y plugins externos al incorporar soporte nativo para audio, video y gráficos 2D/3D con Canvas.

multimedia.html
<!-- Video nativo HTML5 -->
<video
  width="640" height="360"
  controls          <!-- muestra controles -->
  autoplay          <!-- reproducción automática -->
  muted             <!-- sin sonido (necesario para autoplay) -->
  loop              <!-- repetir en bucle -->
  poster="miniatura.jpg">
  <source src="video.mp4"  type="video/mp4"/>
  <source src="video.webm" type="video/webm"/>
  Tu navegador no soporta video.
</video>

<!-- Audio nativo HTML5 -->
<audio controls>
  <source src="cancion.mp3"  type="audio/mpeg"/>
  <source src="cancion.ogg"  type="audio/ogg"/>
</audio>

<!-- Canvas: lienzo para dibujo con JS -->
<canvas id="miCanvas"
        width="400" height="200">
</canvas>
<script>
  const canvas = document.getElementById('miCanvas');
  const ctx = canvas.getContext('2d');
  ctx.fillStyle = '#1565c0';
  ctx.fillRect(50, 50, 200, 100); // x, y, ancho, alto
</script>

<!-- Video de YouTube embebido -->
<iframe
  src="https://www.youtube.com/embed/ID_VIDEO"
  width="560" height="315"
  allowfullscreen>
</iframe>

Atributos globales HTML5

Los atributos globales pueden usarse en cualquier etiqueta HTML. Son fundamentales para la funcionalidad, accesibilidad e interacción con CSS y JavaScript.

id="valor"
Identificador único del elemento. Usado por CSS (#id) y JS.
class="valor"
Clase reutilizable. CSS (.clase) puede aplicarse a varios elementos.
style="css"
Estilos CSS en línea directamente en el elemento.
hidden
Oculta el elemento visualmente y del flujo del documento.
title="texto"
Texto emergente (tooltip) al pasar el cursor.
lang="es"
Idioma del contenido de ese elemento.
tabindex="0"
Controla el orden de tabulación con el teclado.
contenteditable
Permite editar el contenido del elemento directamente.
draggable="true"
Hace el elemento arrastrable con la API Drag and Drop.
data-*="valor"
Atributos personalizados para guardar datos extra. Ej: data-id="5".
aria-label="texto"
Etiqueta de accesibilidad para lectores de pantalla.
role="button"
Indica el rol del elemento a tecnologías de accesibilidad.

Metadatos, SEO y Open Graph

Las etiquetas <meta> dentro del <head> controlan cómo los motores de búsqueda y redes sociales leen e indexan tu página.

head-completo.html
<head>
  <!-- Codificación y viewport -->
  <meta charset="UTF-8"/>
  <meta name="viewport" content="width=device-width"/>

  <!-- SEO básico -->
  <title>Portafolio HTML5 | Diego Emilio</title>
  <meta name="description"
        content="Guía completa de HTML5 para Cultura Digital"/>
  <meta name="keywords"
        content="HTML5, web, programación, diseño"/>
  <meta name="author" content="Diego Emilio Pérez"/>
  <meta name="robots" content="index, follow"/>

  <!-- Open Graph: cómo se ve en redes sociales -->
  <meta property="og:title"       content="Mi Portafolio"/>
  <meta property="og:description"  content="Cultura Digital 2"/>
  <meta property="og:image"       content="preview.jpg"/>
  <meta property="og:type"        content="website"/>

  <!-- Favicon -->
  <link rel="icon" href="favicon.ico" type="image/x-icon"/>

  <!-- Fuentes externas -->
  <link rel="preconnect" href="https://fonts.googleapis.com"/>
  <link rel="stylesheet" href="styles.css"/>
</head>

Geolocation API LocalStorage / SessionStorage Canvas 2D API WebGL (Canvas 3D) Drag and Drop API Web Workers WebSockets History API File API Notifications API Fullscreen API Vibration API Service Workers IndexedDB Web Audio API

Pro tips

Buenas prácticas en HTML5

  • ✓
    Siempre usa etiquetas semánticasUsa <header>, <main>, <section> en lugar de <div> genéricos. El SEO y la accesibilidad te lo agradecerán.
  • ✓
    Un solo <h1> por páginaEl H1 es el título principal y debe ser único. Los H2–H6 organizan la jerarquía de contenido.
  • ✓
    Atributo alt obligatorio en imágenesDescribe el contenido de cada imagen. Si es decorativa, usa alt="" (vacío) para que los lectores de pantalla la ignoren.
  • ✓
    Vincula label con inputUsa el atributo for en <label> con el id del <input> correspondiente para mejorar accesibilidad y usabilidad.
  • ✓
    Script al final del bodyColoca los <script> antes del </body> para que el HTML cargue primero y el usuario vea contenido más rápido.
  • ✓
    Valida tu HTMLUsa el validador oficial del W3C en validator.w3.org para detectar errores de sintaxis en tu código.
  • ✓
    No uses tablas para layoutsLas tablas son para datos tabulares. Para diseñar la estructura visual usa CSS Grid o Flexbox.
  • ✓
    Indenta correctamente el códigoUsa 2 o 4 espacios de indentación de manera consistente. El código limpio es más fácil de mantener y leer.
Herramientas recomendadas: VS Code con extensión Emmet (genera HTML rápido), Live Server (recarga automática), y la extensión HTML CSS Support para autocompletado.
