¿Qué son los lenguajes de programación y diseño?

Un lenguaje de programación o diseño es un sistema formal de símbolos y reglas que permite a los humanos comunicarse con las computadoras. Cada lenguaje fue creado con un propósito específico: algunos para construir sitios web, otros para estructurar documentos, y otros para maquetar y dar estilo visual a interfaces digitales. Conocer estos lenguajes es esencial en la era de la Cultura Digital, ya que son la base sobre la que se construye toda la experiencia digital que vivimos a diario.

01

Lenguajes de Desarrollo Web

Tecnologías para construir, dar estilo e interactividad a sitios y aplicaciones web.

HTML
HyperText Markup Language

Es el esqueleto de toda página web. Define la estructura y el contenido mediante etiquetas semánticas. Fue creado por Tim Berners-Lee en 1991 y actualmente va en su versión HTML5.

Estructura web Semántica SEO Formularios
index.html 
<!-- Estructura básica HTML5 -->
<!DOCTYPE html>
<html lang="es">
  <head>
    <title>Mi Página</title>
  </head>
  <body>
    <h1>Cultura Digital</h1>
    <p>Hola, <strong>mundo</strong></p>
  </body>
</html>
CSS
Cascading Style Sheets

Da vida visual a HTML. Controla colores, tipografías, layouts y animaciones. CSS3 introdujo Flexbox, Grid, transiciones y media queries para el diseño responsivo.

Estilos Animaciones Responsive Layout
styles.css 
/* Variables y estilos */
:root {
  --color-primario: #1565c0;
}
.tarjeta {
  display: flex;
  border-radius: 12px;
  background: var(--color-primario);
  transition: all .3s ease;
}
JavaScript
Lenguaje de scripting web

El único lenguaje nativo de los navegadores web. Agrega interactividad, manipula el DOM, consume APIs y con Node.js también funciona en el servidor. Es el lenguaje más usado del mundo.

Interactividad APIs DOM Node.js
app.js 
// Función con arrow y fetch
const obtenerDatos = async (url) => {
  const res = await fetch(url);
  const data = await res.json();
  return data.filter(x => x.activo);
};

obtenerDatos("/api/items")
  .then(console.log);
Python
Lenguaje de propósito general

Lenguaje interpretado de sintaxis simple y legible. Es el favorito para Inteligencia Artificial, ciencia de datos y automatización. Sus librerías como TensorFlow y Pandas lo hacen indispensable.

IA / ML Data Science Backend Automatización
modelo.py 
# Clasificador simple con Python
import numpy as np

def predecir(datos, umbral=0.5):
    pesos = np.array([0.3, 0.7])
    resultado = np.dot(datos, pesos)
    return resultado > umbral

print(predecir([0.4, 0.8]))  # True
02

Lenguajes de Escritura y Documentación

Lenguajes para estructurar, documentar y publicar contenido de forma legible para humanos y máquinas.

Markdown
Lenguaje de marcado ligero

Creado por John Gruber en 2004, Markdown permite escribir texto con formato usando caracteres simples. Es el estándar en GitHub, documentación técnica y plataformas como Notion o Reddit.

Documentación README Blogs Notas
README.md 
# Título principal
## Subtítulo

Texto **negrita**, _cursiva_ y
`código inline`.

- Elemento de lista
- Otro elemento

[Enlace](https://ejemplo.com)
![Imagen](logo.png)

> Cita de bloque importante
XML
eXtensible Markup Language

Lenguaje de marcado para almacenar y transportar datos con estructura jerárquica. Es la base de muchos formatos estándar como SVG, RSS, Android Layouts y servicios web SOAP.

Datos Configuración RSS SVG
datos.xml 
<?xml version="1.0"?>
<estudiantes>
  <alumno id="1">
    <nombre>Diego</nombre>
    <materia>
      Cultura Digital
    </materia>
    <calificacion>10</calificacion>
  </alumno>
</estudiantes>
JSON
JavaScript Object Notation

Formato ligero de intercambio de datos basado en texto. Es el estándar universal para comunicación entre APIs REST y aplicaciones web. Fácil de leer por humanos y máquinas.

APIs REST Configuración Bases de datos Almacenamiento

LaTeX
Sistema de composición tipográfica

Sistema de preparación de documentos de alta calidad tipográfica. Estándar en publicaciones científicas, tesis académicas y artículos matemáticos por su capacidad para renderizar fórmulas complejas.

Tesis Fórmulas matemáticas Artículos científicos

03

Lenguajes de Diseño y Maquetación

Herramientas y lenguajes especializados en la presentación visual, gráficos y composición de interfaces.

SVG
Scalable Vector Graphics

Formato vectorial basado en XML para gráficos 2D. Sus imágenes se escalan sin perder calidad a cualquier tamaño. Ideal para íconos, logotipos, animaciones e ilustraciones web interactivas.

Íconos Logotipos Animaciones Gráficas
grafico.svg 
<!-- Gráfico vectorial básico -->
<svg viewBox="0 0 100 100"
     xmlns="http://www.w3.org/2000/svg">

  <circle cx="50" cy="50"
          r="40" fill="#42a5f5"/>

  <text x="50" y="55"
        text-anchor="middle"
        fill="white">Hola</text>
</svg>
SASS
Syntactically Awesome Stylesheets

Preprocesador CSS que añade variables, anidamiento, mixins, herencia y funciones. Compila a CSS estándar y hace el código de estilos más organizado, reutilizable y mantenible en proyectos grandes.

Preprocesador CSS Variables Mixins Nesting
estilos.scss 
// Variables y mixin SASS
$primario: #1565c0;
$radio: 12px;

@mixin tarjeta($color) {
  background: $color;
  border-radius: $radio;
  &:hover {
    opacity: .85;
  }
}
.btn { @include tarjeta($primario); }
Figma
Herramienta de diseño UI/UX

Plataforma colaborativa de diseño de interfaces. Permite crear wireframes, prototipos interactivos y sistemas de diseño. Es el estándar de la industria para diseño UI/UX y trabaja con Design Tokens en JSON.

UI/UX Prototipos Wireframes Design System

    "md": "16px",
    "lg": "32px"
  }
}
SQL
Structured Query Language

Lenguaje estándar para gestionar bases de datos relacionales. Permite consultar, insertar, actualizar y eliminar datos. Es fundamental en cualquier aplicación web que maneje información persistente.

Bases de datos Consultas Backend Reportes
consulta.sql 
-- Consulta con filtro y orden
SELECT
  nombre,
  especialidad,
  calificacion
FROM alumnos
WHERE escuela = 'CBTis 144'
  AND activo = TRUE
ORDER BY calificacion DESC
LIMIT 10;

Reflexión personal

Conocer los lenguajes de programación, escritura y diseño es fundamental para cualquier estudiante de la era digital. Cada lenguaje fue creado para resolver un problema específico, y juntos forman un ecosistema que hace posible todo lo que vemos en internet: desde un simple botón hasta un modelo de inteligencia artificial. En la materia de Cultura Digital aprendemos que no es necesario dominarlos todos, pero sí entender para qué sirve cada uno y cómo se relacionan entre sí, ya que eso nos da una visión integral del mundo tecnológico en el que vivimos y trabajaremos.
