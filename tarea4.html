01
Introducción

¿Qué es CSS3?

CSS (Cascading Style Sheets — Hojas de Estilo en Cascada) es el lenguaje que controla la apariencia visual de las páginas web. Si HTML es el esqueleto del sitio, CSS es su piel, ropa y decoración. CSS3 es la versión actual, que añadió módulos independientes como animaciones, variables, Grid, Flexbox y filtros visuales.

CSS funciona seleccionando elementos HTML y aplicándoles reglas de estilo: colores, fuentes, márgenes, posiciones y efectos. Fue creado por Håkon Wium Lie en 1996 y es un estándar mantenido por el W3C.

CSS3 ≠ CSS4: A diferencia de HTML, CSS no tiene versiones mayores después de CSS3. En su lugar, el W3C publica módulos independientes actualizados (CSS Grid Level 2, CSS Color Level 5, etc.). Por eso se dice informalmente "CSS3" para referirse al CSS moderno actual.
  • 1
    HTML estructura el contenidoDefine qué elementos existen: títulos, párrafos, botones, imágenes.
  • 2
    CSS estiliza el contenidoDecide cómo se ve cada elemento: color, tamaño, posición, sombra, animación.
  • 3
    La cascada resuelve conflictosSi dos reglas aplican al mismo elemento, la especificidad y el orden determinan cuál gana.

Sintaxis y formas de aplicar CSS

Una regla CSS tiene dos partes: un selector (qué elemento) y una declaración (qué estilo). La declaración es un par propiedad–valor entre llaves.

sintaxis.css
/* Anatomía de una regla CSS */
selector {
  propiedad: valor;
  otra-propiedad: otro-valor;
}

/* Ejemplo real */
h1 {
  color: #264de4;
  font-size: 2rem;
  text-align: center;
}
3-formas.html
<!-- 1. CSS EXTERNO (recomendado) -->
<link rel="stylesheet" href="styles.css"/>

<!-- 2. CSS INTERNO (en el <head>) -->
<style>
  body { background: #f5f0e8; }
</style>

<!-- 3. CSS EN LÍNEA (evitar siempre que sea posible) -->
<p style="color: red; font-weight: bold;">
  Texto rojo
</p>

Selectores CSS — todos los tipos

Los selectores son la clave de CSS: determinan a qué elementos HTML se aplican los estilos. CSS3 ofrece una gran variedad de selectores para apuntar a cualquier elemento con precisión quirúrgica.

selectores.css
/* ── SELECTORES BÁSICOS ─────────── */
*          { box-sizing: border-box; }  /* universal */
p          { color: #333; }             /* etiqueta */
.btn       { padding: 8px; }          /* clase */
#logo      { width: 120px; }         /* id */

/* ── SELECTORES DE COMBINACIÓN ─── */
div p      { }   /* descendiente: p dentro de div */
div > p    { }   /* hijo directo */
h1 + p     { }   /* hermano adyacente inmediato */
h1 ~ p     { }   /* todos los hermanos siguientes */

/* ── SELECTORES DE ATRIBUTO ─────── */
[type="text"]   { }  /* atributo igual a */
[href^="https"] { }  /* atributo empieza con */
[src$=".jpg"]   { }  /* atributo termina con */
[class*="btn"]  { }  /* atributo contiene */

/* ── PSEUDO-CLASES DE ESTADO ────── */
a:hover         { color: blue; }   /* al pasar cursor */
a:visited       { }   /* enlace visitado */
input:focus     { }   /* campo con foco */
input:disabled  { }   /* campo deshabilitado */
input:checked   { }   /* checkbox marcado */
:not(.activo)   { }   /* negación */

/* ── PSEUDO-CLASES ESTRUCTURALES ── */
li:first-child  { }   /* primer hijo */
li:last-child   { }   /* último hijo */
li:nth-child(2) { }   /* hijo número 2 */
li:nth-child(odd)  { } /* hijos impares */
li:nth-child(even) { } /* hijos pares */
p:nth-child(3n+1)  { } /* cada 3, empezando en 1 */

/* ── PSEUDO-ELEMENTOS ───────────── */
p::first-line  { }  /* primera línea */
p::first-letter{ }  /* primera letra */
.btn::before  { content: "→"; }  /* antes del contenido */
.btn::after   { content: "✓"; }  /* después del contenido */
::selection   { background: #264de4; } /* texto seleccionado */
::placeholder { color: #aaa; }  /* placeholder de input */

/* ── AGRUPAR SELECTORES ─────────── */
h1, h2, h3, h4 {
  font-family: 'Bebas Neue', sans-serif;
}

Especificidad y cascada

Cuando dos reglas CSS se aplican al mismo elemento, el navegador usa la especificidad para decidir cuál gana. Cada tipo de selector suma puntos de especificidad.

Estilos en línea (style="")
1,0,0,0
Máxima
Selectores de ID (#id)
0,1,0,0
Alta
Clases, atributos, pseudo-clases
0,0,1,0
Media
Etiquetas y pseudo-elementos
0,0,0,1
Baja
Selector universal (*)
0,0,0,0
Nula
especificidad.css
/* Especificidad: 0,0,0,1 → gana la última */
p           { color: black; }

/* Especificidad: 0,0,1,0 → gana sobre p */
.texto      { color: blue; }

/* Especificidad: 0,1,0,0 → gana sobre .texto */
#principal  { color: red; }

/* !important: rompe la cascada (evitar) */
p           { color: green !important; }

/* Herencia: los hijos heredan del padre */
body        { font-family: Poppins; }
/* todos los hijos heredan font-family */

Tipografía CSS3

tipografia.css
/* ── FUENTES PERSONALIZADAS ──────── */
@font-face {
  font-family: 'MiFuente';
  src: url('fuente.woff2') format('woff2');
  font-weight: normal;
  font-display: swap;
}

/* ── PROPIEDADES DE TEXTO ─────────── */
.texto {
  font-family:   'Poppins', sans-serif;
  font-size:     1rem;         /* 16px por defecto */
  font-weight:   600;           /* 100–900 */
  font-style:    italic;
  line-height:   1.6;           /* interlineado */
  letter-spacing: .05em;       /* espacio entre letras */
  word-spacing:   2px;
  text-align:    center;        /* left|right|center|justify */
  text-transform: uppercase;   /* uppercase|lowercase|capitalize */
  text-decoration: underline;  /* underline|line-through|none */
  text-shadow:   2px 2px 4px rgba(0,0,0,.3);
  white-space:   nowrap;        /* evita saltos de línea */
  overflow:      hidden;
  text-overflow: ellipsis;     /* texto cortado con … */
}

/* ── UNIDADES DE MEDIDA ──────────── */
/*  px  → píxeles absolutos
    em  → relativo al padre
    rem → relativo al :root (html)
    %   → porcentaje del padre
    vw  → % del ancho del viewport
    vh  → % del alto del viewport
    ch  → ancho del carácter '0'
    clamp(min, preferido, max) → fluido  */
h1 {
  font-size: clamp(1.5rem, 5vw, 4rem);
}

El Box Model — modelo de caja

Todo elemento HTML es una caja rectangular compuesta por cuatro capas concéntricas. Entender el box model es esencial para controlar espaciados y tamaños.

margin
border
padding
content
box-model.css
.caja {
  /* TAMAÑO del contenido */
  width:      300px;
  height:     200px;
  min-width:  200px;
  max-width:  100%;

  /* RELLENO interno (padding) */
  padding:    16px;              /* todos lados */
  padding:    8px 16px;         /* vertical horizontal */
  padding:    4px 8px 12px 16px; /* top right bottom left */
  padding-top: 20px;             /* lado individual */

  /* MARGEN externo (margin) */
  margin:     0 auto;           /* centrar elemento */
  margin-bottom: 24px;

  /* BORDE */
  border:     2px solid #264de4;
  border-radius: 12px;

  /* MODELO DE CAJA recomendado */
  box-sizing: border-box;
  /* border-box: width incluye padding y border */
  /* content-box (default): width solo el contenido */

  /* OVERFLOW: qué hacer cuando el contenido desborda */
  overflow:   hidden;    /* hidden|scroll|auto|visible */
}

Bordes, sombras y efectos CSS3

bordes-sombras.css
.tarjeta {
  /* BORDER-RADIUS: esquinas redondeadas */
  border-radius: 16px;
  border-radius: 50%;            /* círculo */
  border-radius: 8px 0 8px 0;  /* diagonal */

  /* BORDER personalizado */
  border:       2px solid #264de4;
  border-style: dashed;    /* solid|dashed|dotted|double */
  border-left:  4px solid #264de4; /* solo un lado */
  border-image: linear-gradient(#264de4,#90caf9) 1;

  /* BOX-SHADOW: sombra de caja */
  box-shadow: 0 4px 20px rgba(13,43,85,.15);
  /*  x   y   blur spread  color  */
  box-shadow: 0 0 0 3px #264de4;  /* outline glow */
  box-shadow: inset 0 2px 8px rgba(0,0,0,.2); /* interna */
  /* múltiples sombras separadas por coma */
  box-shadow:
    0 4px 12px rgba(0,0,0,.1),
    0 0   0    2px #264de4;

  /* OUTLINE: contorno exterior (no afecta layout) */
  outline:        2px solid #264de4;
  outline-offset: 4px;

  /* OPACITY y VISIBILITY */
  opacity:    0.85;
  visibility: hidden;   /* invisible pero ocupa espacio */
}

/* ── DISPLAY ─────────────────────── */
.elemento {
  display: block;         /* ocupa toda la fila */
  display: inline;        /* solo su contenido */

  position: relative;  /* desde su posición normal */

  position: absolute;  /* respecto al padre relative */

.fijo      {
  position: fixed;      /* fijo al viewport (navbar) */

}
.sticky    {
  position: sticky;     /* se "pega" al hacer scroll */

}

/* z-index: orden de capas (requiere position) */

Flexbox — diseño unidimensional

Flexbox (Flexible Box) es el sistema de layout de CSS3 para distribuir elementos en una sola dirección (fila o columna). Es ideal para barras de navegación, tarjetas horizontales y centrado.

🔍 Demo: justify-content y align-items

flexbox.css
/* ── CONTENEDOR FLEX ────────────── */
.contenedor {
  display:         flex;
  flex-direction:  row;          /* row|row-reverse|column|column-reverse */
  flex-wrap:       wrap;         /* nowrap|wrap|wrap-reverse */
  gap:             16px;         /* espacio entre items */

  /* Alineación en el eje principal (horizontal) */
  justify-content: space-between;
  /* flex-start | flex-end | center | space-around
     space-between | space-evenly */

  /* Alineación en el eje secundario (vertical) */
  align-items:    center;
  /* flex-start | flex-end | center | stretch | baseline */

  /* Alineación de múltiples filas */
  align-content:  flex-start;
}

/* ── ITEMS FLEX ─────────────────── */
.item {
  flex-grow:   1;    /* crece para ocupar espacio disponible */
  flex-shrink: 0;    /* no se encoge */
  flex-basis:  200px; /* tamaño base */
  flex: 1 0 200px;   /* shorthand: grow shrink basis */

  align-self:  flex-end; /* sobreescribe align-items del padre */
  order:       2;        /* orden visual (default 0) */
}

/* Patrón común: centrar perfectamente */
.centrar-todo {
  display:         flex;
  justify-content: center;
  align-items:    center;
  min-height:     100vh;
}

CSS Grid — diseño bidimensional

CSS Grid es el sistema más poderoso de layout en CSS. Funciona en dos dimensiones simultáneamente (filas y columnas), perfecto para layouts de página completos.

🔍 Demo: grid-template-columns auto-fill

grid.css
/* ── CONTENEDOR GRID ─────────────── */
.grid {
  display: grid;

  /* Columnas */
  grid-template-columns: 1fr 2fr 1fr;
  /* fr = fracción del espacio disponible */
  grid-template-columns: repeat(3, 1fr);
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  grid-template-columns: 200px 1fr;  /* sidebar + main */

  /* Filas */
  grid-template-rows:    80px 1fr 60px;

  /* Espaciado */
  gap:                    20px;
  column-gap:             24px;
  row-gap:                16px;

  /* Áreas con nombre (layout visual) */
  grid-template-areas:
    "header  header"
    "sidebar main  "
    "footer  footer";
}

/* ── ITEMS GRID ──────────────────── */
.header  { grid-area: header;  }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main;    }
.footer  { grid-area: footer;  }

/* Span: elemento que ocupa varias celdas */
.destacado {
  grid-column: 1 / 3;  /* de línea 1 a línea 3 */
  grid-column: span 2; /* ocupa 2 columnas */
  grid-row:    span 2; /* ocupa 2 filas */
}

Responsive Design y Media Queries

El diseño responsivo hace que los sitios web funcionen bien en cualquier tamaño de pantalla. Las media queries son la herramienta clave para aplicar estilos según el dispositivo.

responsive.css
/* ── BREAKPOINTS COMUNES ─────────── */
/*
  xs:  < 480px  → móvil pequeño
  sm:  < 640px  → móvil
  md:  < 768px  → tablet
  lg:  < 1024px → laptop
  xl:  < 1280px → desktop
  2xl: > 1280px → pantalla grande
*/

/* Mobile-first: primero móvil, luego crece */
.grid {
  grid-template-columns: 1fr;  /* móvil: 1 columna */
}
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Condiciones múltiples */
@media (min-width: 600px) and (max-width: 900px) {
  /* solo tablets */
}

/* Orientación del dispositivo */
@media (orientation: landscape) { }

/* Preferencia de movimiento reducido (accesibilidad) */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; }
}

/* Tema oscuro automático */
@media (prefers-color-scheme: dark) {
  body { background: #0a1628; color: #fff; }
}

/* Contenedor responsive ideal */
.container {
  max-width:  1200px;
  margin:    0 auto;
  padding:   0 clamp(16px, 4vw, 40px);
}

Transiciones CSS3

Las transiciones crean cambios suaves entre dos estados de un elemento (por ejemplo: normal → hover). Son la forma más sencilla de añadir animación sin JavaScript.

🔍 Demo: pasa el cursor sobre los botones
transiciones.css
/* ── PROPIEDAD TRANSITION ─────────── */
.boton {
  background: #264de4;
  /* propiedad  duración  función    retardo */
  transition: all        .3s      ease       0s;

  /* Múltiples transiciones */
  transition:
    background .3s ease,
    transform  .2s ease-out,
    box-shadow .3s ease;
}
.boton:hover {
  background:  #7eb3ff;
  transform:   translateY(-4px);
  box-shadow:  0 8px 24px rgba(38,77,228,.4);
}

/* ── FUNCIONES DE TIMING ─────────── */
/* ease      → lento-rápido-lento (default)
   ease-in   → empieza lento
   ease-out  → termina lento
   ease-in-out → ambos lados lentos
   linear    → velocidad constante
   steps(4)  → movimiento a pasos
   cubic-bezier(.17,.67,.83,.67) → personalizado */

/* ── TRANSFORM: transformaciones 2D/3D ── */
.transformable {
  transform: translateX(20px);
  transform: translateY(-10px);
  transform: scale(1.1);
  transform: rotate(45deg);
  transform: skew(15deg);
  transform: perspective(500px) rotateY(30deg);
  transform-origin: top left;
}

Animaciones CSS3 con @keyframes

Las animaciones CSS3 permiten crear movimiento complejo entre múltiples estados usando @keyframes, sin necesidad de JavaScript.

spin
pulse
slide

animaciones.css
/* ── DEFINIR KEYFRAMES ────────────── */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

@keyframes pulse {
  0%, 100% { transform: scale(1);    }
  50%      { transform: scale(1.15); }
}

@keyframes fadeIn {
  0%   { opacity: 0; transform: translateY(20px); }
  100% { opacity: 1; transform: translateY(0); }
}

/* ── APLICAR ANIMACIÓN ────────────── */
.spinner {
  /* nombre  duración  función  retardo  iteraciones  dirección  fill  estado */
  animation: spin     1s       linear   0s      infinite     normal     both  running;
}

.aparecer {
  animation: fadeIn .6s ease-out forwards;
}

/* Animar con retardo escalonado */
.item:nth-child(1) { animation-delay: 0s;   }
.item:nth-child(2) { animation-delay: .1s;  }
.item:nth-child(3) { animation-delay: .2s;  }

Variables CSS (Custom Properties)

Las variables CSS (formalmente Custom Properties) permiten almacenar valores reutilizables en el CSS. A diferencia de las variables de SASS, las variables CSS son dinámicas: pueden cambiarse en tiempo real con JavaScript o con media queries.

variables.css
/* ── DEFINIR VARIABLES ────────────── */
:root {
  /* Variables globales (toda la página) */
  --color-primario:    #264de4;
  --color-secundario:  #7eb3ff;
  --color-texto:       #111111;
  --fondo:             #f5f0e8;
  --radio-borde:       12px;
  --sombra:            0 4px 20px rgba(0,0,0,.1);
  --fuente-base:       'Poppins', sans-serif;
  --transicion:        all .3s ease;
}

/* ── USAR VARIABLES ───────────────── */
.tarjeta {
  background:    var(--fondo);
  color:         var(--color-texto);
  border-radius: var(--radio-borde);
  box-shadow:    var(--sombra);
  transition:    var(--transicion);
  /* var(--variable, valor-por-defecto) */
  font-size:     var(--tamaño-texto, 1rem);
}

/* ── TEMA OSCURO CON VARIABLES ────── */
@media (prefers-color-scheme: dark) {
  :root {
    --color-texto: #ffffff;
    --fondo:       #0a1628;
  }
}

/* ── MODIFICAR CON JAVASCRIPT ─────── */

Pro tips

Buenas prácticas en CSS3

  • ✓
    Usa box-sizing: border-box globalmenteAplica * { box-sizing: border-box; } al inicio de cada proyecto. Evita desbordamientos inesperados.
  • ✓
    Mobile-first siempreDiseña primero para móvil y amplía con min-width en tus media queries. Es más fácil agregar que quitar.
  • ✓
    Usa variables CSS para colores y espaciadosDefine una paleta de variables en :root. Cambiar un color en un solo lugar actualizará todo el sitio.
  • ✓
    Evita !importantEl uso de !important es señal de que la especificidad está mal organizada. Refactoriza los selectores en su lugar.
  • ✓
    Prefiere clases sobre IDs para estilosLos IDs tienen especificidad alta y dificultan la reutilización. Usa clases (.btn, .card) para estilar.
  • ✓
    Usa rem para tipografía, px para bordesrem se escala con la preferencia del usuario. px es bueno para detalles pequeños y fijos.
  • ✓
    Ordena las propiedades de forma consistenteUna convención recomendada: posicionamiento → display → dimensiones → box model → tipografía → visual → otros.
  • ✓
    Prueba el contraste de coloresLa relación de contraste entre texto y fondo debe ser al menos 4.5:1 para cumplir con las pautas WCAG de accesibilidad.
Herramientas recomendadas: VS Code con extensión CSS Peek y IntelliSense, Autoprefixer para compatibilidad entre navegadores, Can I Use (caniuse.com) para verificar soporte de propiedades, y DevTools del navegador para inspeccionar y experimentar en tiempo real.

Reflexión personal

CSS3 transformó el diseño web al hacer posibles efectos que antes requerían imágenes estáticas, Flash o JavaScript complejo. Hoy, con solo unas líneas de CSS podemos crear animaciones fluidas, layouts adaptativos y experiencias visuales sofisticadas. Para un estudiante de Inteligencia Artificial, entender CSS3 es comprender que la presentación de la información es tan importante como la información misma: los mejores modelos de IA pierden impacto si su interfaz visual no comunica correctamente sus resultados. CSS es el puente entre la lógica y la percepción humana.
