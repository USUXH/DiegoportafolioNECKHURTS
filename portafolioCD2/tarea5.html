Variables y Tipos

En Python las variables son etiquetas que apuntan a objetos en memoria. No se declara el tipo — se infiere automáticamente.

🔵 Declaración

# Sin declarar tipo explícito nombre = "Python" version = 3.12 activo = True nada = None # Múltiple asignación x, y, z = 1, 2, 3

🟡 Type Hints (Python 3.5+)

edad: int = 25 precio: float = 9.99 mensaje: str = "Hola" items: list[str] = []

🟢 Naming Conventions

# snake_case para variables mi_variable = "bien" # SCREAMING_SNAKE para constantes PI = 3.14159 MAX_SIZE = 100 # PascalCase para clases class MiClase: pass

🩷 type() e isinstance()

type(42) # <class 'int'> type("hola") # <class 'str'> isinstance(3, int) # True isinstance("a", (str, int)) # True

Tipos de Datos

Python es fuertemente tipado pero dinámico. Conoce los tipos nativos y sus características.

int

Enteros de precisión arbitraria

x = 42 y = -100 z = 10_000
float

Números de punto flotante IEEE 754

pi = 3.14 e = 2.718e0
str

Cadenas inmutables Unicode

s = "hola" f = f"{s}!" r = r"\n"
bool

True / False (subclase de int)

a = True b = False c = bool(0)
bytes

Secuencia de bytes inmutable

b = b"datos" b2 = bytes(4)
complex

Números complejos

c = 3 + 2j c.real # 3.0 c.imag # 2.0

🔵 F-Strings (Python 3.6+) — la forma moderna

nombre = "Mundo" version = 3.12 pi = 3.14159 print(f"Hola, {nombre}!") # Hola, Mundo! print(f"Python {version}") # Python 3.12 print(f"Pi = {pi:.2f}") # Pi = 3.14 print(f"{42 * 2 =}") # 42 * 2 = 84

Operadores

Python ofrece operadores aritméticos, de comparación, lógicos, bit a bit y de identidad/pertenencia.

Aritméticos
10 + 3 # 13 suma 10 - 3 # 7 resta 10 * 3 # 30 multiplicación 10 / 3 # 3.33 división 10 // 3 # 3 división entera 10 % 3 # 1 módulo 2 ** 8 # 256 potencia
Comparación
5 == 5 # True igual 5 != 3 # True distinto 5 > 3 # True mayor 5 < 3 # False menor 5 >= 5 # True mayor/igual 5 <= 6 # True menor/igual
Lógicos
True and False # False True or False # True not True # False # Short-circuit evaluation x = None y = x or "default" # "default"
Identidad y Pertenencia
a = [1, 2] b = a b is a # True misma ref b is not a # False 3 in [1,2,3] # True "a" in "abc" # True

Control de Flujo

Condicionales, bucles y el nuevo match-case para controlar la ejecución del programa.

🟢 if / elif / else

x = 42 if x > 100: print("grande") elif x > 10: print("mediano") else: print("pequeño") # Ternario msg = "par" if x % 2 == 0 else "impar"

🟣 match-case (Python 3.10+)

cmd = "quit" match cmd: case "quit": print("Saliendo") case "help": print("Ayuda") case _: print("Desconocido")

🔵 for / while

# for con range for i in range(5): print(i) # 0 1 2 3 4 # for con enumerate for i, v in enumerate(["a","b"]): print(i, v) # while con break/continue n = 0 while n < 5: if n == 3: break n += 1

🟡 Comprehensions

# Lista cuadrados = [x**2 for x in range(10)] # Con condición pares = [x for x in range(20) if x%2==0] # Diccionario d = {k: k**2 for k in range(5)}

Funciones

Las funciones son ciudadanos de primera clase en Python. Pueden pasarse como argumentos, retornarse y asignarse a variables.

Definición básica
def saludar(nombre: str) -> str: """Retorna un saludo.""" return f"Hola, {nombre}!" # Parámetros con default def potencia(base, exp=2): return base ** exp
*args y **kwargs
def suma(*nums): return sum(nums) suma(1, 2, 3, 4) # 10 def info(**datos): for k, v in datos.items(): print(f"{k}: {v}") info(nombre="Ana", edad=30)
Lambda y funciones de orden superior
# Lambda doble = lambda x: x * 2 # map, filter, reduce nums = [1,2,3,4] dobles = list(map(doble, nums)) pares = list(filter(lambda x: x%2==0, nums)) # Sorted con key sorted(nums, key=lambda x: -x)
Decoradores
def log(func): def wrapper(*a, **k): print(f"→ {func.__name__}") return func(*a, **k) return wrapper @log def saludar(): print("Hola!") saludar() # → saludar \n Hola!

Colecciones

Cuatro estructuras de datos fundamentales: lista, tupla, diccionario y conjunto.

list — mutable, ordenada
l = [1, "dos", 3.0, True] l.append(5) l.insert(0, 0) l.pop() l[1:3] # slicing l[::-1] # invertir len(l) # longitud
tuple — inmutable, ordenada
t = (1, 2, 3) x, y, z = t # unpacking t[0] # 1 t.count(1) # 1 t.index(2) # 1 # Named tuple from collections import namedtuple Punto = namedtuple("Punto", "x y")
dict — clave-valor, ordenado (3.7+)
d = {"nombre": "Ana", "edad": 30} d["email"] = "a@b.com" d.get("x", "default") d.keys() d.values() d.items() del d["edad"]
set — sin duplicados, no ordenado
s = {1, 2, 3, 2, 1} # {1,2,3} s.add(4) s.discard(2) s | {5} # unión s & {1,3} # intersección s - {1} # diferencia

Programación Orientada a Objetos

Clases, herencia, encapsulamiento y polimorfismo — los cuatro pilares de la POO en Python.

class Animal

atributos: nombre, sonido

métodos: __init__, hablar, __repr__

↓
class Perro(Animal)

hereda: nombre, sonido, hablar

sobrescribe: hablar

agrega: raza, traer

↓
instancia = Perro("Rex", "Labrador")

instancia.hablar() → "Rex dice: ¡Guau!"

class Animal: def __init__(self, nombre, sonido): self.nombre = nombre self._sonido = sonido # "privado" def hablar(self): return f"{self.nombre} dice: {self._sonido}" def __repr__(self): return f"Animal({self.nombre!r})" class Perro(Animal): def __init__(self, nombre, raza): super().__init__(nombre, "¡Guau!") self.raza = raza def hablar(self): # polimorfismo return f"{self.nombre} dice: ¡Guau!" @property def info(self): return f"{self.nombre} ({self.raza})" rex = Perro("Rex", "Labrador") rex.hablar() # Rex dice: ¡Guau! isinstance(rex, Animal) # True

🟡 Dataclasses (Python 3.7+) — la forma moderna

from dataclasses import dataclass, field @dataclass class Producto: nombre: str precio: float tags: list[str] = field(default_factory=list) def con_iva(self, tasa=0.16): return self.precio * (1 + tasa) p = Producto("Libro", 150.0, ["educación"]) print(p) # Producto(nombre='Libro', precio=150.0, ...) print(p.con_iva()) # 174.0

Manejo de Excepciones

Python usa try/except/else/finally para manejo robusto de errores. Las excepciones son clases.

🩷 try / except / else / finally

try: resultado = 10 / 0 except ZeroDivisionError: print("¡División por cero!") except (TypeError, ValueError) as e: print(f"Error: {e}") else: print("Sin errores") # si no hubo excepción finally: print("Siempre ejecuta")

🔵 Excepciones personalizadas

class SaldoInsuficienteError(Exception): def __init__(self, saldo, monto): self.saldo = saldo self.monto = monto super().__init__( f"Saldo {saldo} < monto {monto}" ) def retirar(saldo, monto): if monto > saldo: raise SaldoInsuficienteError(saldo, monto) return saldo - monto

🟢 Context Managers (with)

# Archivos se cierran solos with open("datos.txt", "r") as f: contenido = f.read() # contextlib from contextlib import suppress with suppress(FileNotFoundError): open("no_existe.txt")
